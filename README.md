# ms_basecall / cudacall → Ascend 910B · 迁移与基线文档集

> 本项目是一个 GPU（CUDA + TensorRT）碱基识别 SDK 向昇腾 Ascend 910B 迁移工程中，**可公开的工程文档集合**。
> 内容覆盖：项目梳理与计划、缺口清单、环境搭建手册、评测方法与报告格式、文档治理与路线图。

## 这是什么 / 不是什么

**是**：一套可复用的工程方法论文档——怎么盘点迁移缺口、怎么搭基线环境、怎么定义精度/性能评测口径、怎么规划多阶段交付。

**不是**：不含客户数据、不含验收合同原文、不含模型文件与二进制、不含任何账号与地址（本仓为**脱敏版**，全部主机名/用户名/IP 已替换为占位符）。

## 核心内容速览

**两类基线**
- **L0 GPU 基线**：原 CUDA 版在 NVIDIA 卡上跑出参考结果（权威基准，合同口径为 RTX 4090）；
- **L1 NPU 基线**：迁移版在 910B 上跑，与 L0 对拍。

**评测不只看吞吐**（详见 05）
- 精度 8 项：Modal identity diff、Q_Read_Mean diff、逐位 sequence/qstring、moves/chunk_type 一致、run-to-run 确定性、分物种细分；
- 性能 9 项：十进制吞吐（合同口径）、兼容 2^20 口径、延迟分位、分段耗时、显存、利用率、batch×T 扫描、相对 4090 比值、冷热启动；
- 稳定性 4 项：吞吐漂移、显存漂移、异常返回码不退出、7 天 soak；
- 报告固定 6 段 + PASS / CONDITIONAL / FAIL / INVALID 判定。

**环境搭建**（详见 06）
- 体检脚本 + 一键脚本（幂等、可断点续跑、自动识别 GPU 算力与空闲卡）；
- 版本配套铁律：**TensorRT 必须 8.6.x**（源码用 `executeV2`，TRT 10 已删除该 API）；
- 替换层设计：真模型/真库到位后只改 3 行路径，代码零改动。
