## 核心内容速览

**两类基线**：L0 GPU 基线（CUDA 版参考结果，验收参照为 RTX 4090）→ L1 NPU 基线（910B 与 L0 对拍）。

**评测不只看吞吐**（[30](docs/30-验证与评测/30_评测报告格式规范.md)）
- 精度 8 项：Modal identity diff、Q_Read_Mean diff、逐位 sequence/qstring、moves/chunk_type 一致、run-to-run 确定性、分物种细分；
- 性能 9 项：十进制吞吐（验收口径）、兼容 2^20 口径、延迟分位、分段耗时、显存、利用率、batch×T 扫描、相对 4090 比值、冷热启动；
- 稳定性 4 项：吞吐漂移、显存漂移、异常返回码不退出、7 天 soak；
- 报告固定 6 段（R0–R5）+ PASS / CONDITIONAL / FAIL / INVALID 判定。

**环境搭建**（[10](docs/10-环境与构建/10_环境搭建手册.md)）
- 体检脚本 + 一键脚本（幂等、可断点续跑、自动识别 GPU 算力与空闲卡）；
- 版本铁律：**TensorRT 必须 8.6.x**（源码用 `executeV2`，TRT 10 已删除该 API）；
- 替换层设计：真模型/真库到位后只改 3 行路径，代码零改动。

**文档治理**（[91](docs/90-治理与规范/91_文档规划与路线图.md)）
- 分层 L0–L4、编号段、元数据头、状态机（草稿→评审→定稿→归档）；
- 七阶段路线图（每阶段：步骤 / Gate / 文档产出）、文档任务 DOC-001~012。
